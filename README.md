# 💧 WaterGo — Water Delivery Order App

Mobile application built for water refilling station owners to record and manage customer orders. Developed using **FlutterFlow**.

## 📱 App Pages
- 🏠 **Home Page** — Welcome screen with navigation buttons
- ➕ **New Order** — Form to record customer name, delivery address, and number of jugs
- 📋 **View Orders** — List of all recorded orders
- 👤 **Customers** — Customer list page
